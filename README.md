# NicheIntel 细分岗位情报官 Skill

为用户所在细分岗位生成可执行情报简报。融合行业竞品/对手动态与前沿科研、指南、监管信号，按 **Context-Core-Impact-Action** 框架输出。

## 核心能力

- **岗位画像锁定**：大类 → 子类 → 细分岗位，精准定位决策场景
- **五级信源栈**：S1 硬信号（监管/指南）→ S2 证据信号（顶刊/RCT）→ S3 产业信号 → S4 现场信号 → S5 舆情线索
- **信号分级**：A（改变实践）/ B（强化修正）/ C（观察池）/ N（噪声）
- **3C+A 提炼法则**：每条信号写满 Context、Core、Impact、Action 四段
- **本地化闸门**：可及性、合规、培训、成本、与国内路径冲突检查
- **四种输出模式**：快讯 / 班前简报 / 周报 / 深挖

## 适用行业路径

| 大类 | 子类 | 细分岗位示例 |
|------|------|-------------|
| 医疗 | 医院 | 急救科医生、心内科主任、ICU 护士长 |
| 科技 | 半导体 | 研发工程师、工艺工程师、封测产线经理 |
| 汽车 | 新能源 | 销售顾问、交付经理、售后技术主管 |
| 金融 | 投资 | AI 板块研究员、医药行业分析师 |
| 制造 | 高端装备 | 产线工程师、采购经理、质量总监 |

## 快速开始

1. 告知你的行业路径（如：医疗 → 医院 → 急救科负责人）
2. 选择决策场景（术式与流程 / 用药与耗材 / 设备与产线 / 定价与话术 / 合规与准入 / 人才与培训）
3. 选择输出模式（快讯 / 班前简报 / 周报 / 深挖）
4. 获取可执行情报简报

## 使用原则

- 禁止虚构文献、作者、数值；检索不到就标明"未核到全文"
- 不确定就写不确定，禁止脑补未检索到的数据
- 中文输出；术语可保留英文缩写并给中文
- 没有动作的情报视为未完成
